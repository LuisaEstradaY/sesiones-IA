# Entrega: ejercicios de IA

Este repositorio reúne los tres ejercicios trabajados en las sesiones de IA.

## Ejercicio 1 – Algoritmo

El programa en Java solicita tres números enteros y los muestra de menor a
mayor. También funciona cuando hay números iguales.

- Código: [secuenciaDeNumeros/algoritmo.java](./secuenciaDeNumeros/algoritmo.java)
- Para ejecutarlo: compila con `javac secuenciaDeNumeros/algoritmo.java` y
  ejecuta con `java -cp secuenciaDeNumeros CalcularOrden`.
